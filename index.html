AI API Settings

Pick a provider to auto-fill its endpoint and default model, or enter any OpenAI-compatible endpoint. Your key is stored only in this browser.

Not tested
The endpoint must allow browser CORS. When enabled, new windows are generated by AI; when disabled, the built-in offline templates are used.

Wallpaper

Choose an image from this device. It is stored only in this browser and restores on the next visit.

Appearance

Choose the system theme. Windows, menus and newly generated apps follow this setting.

Lock screen

Set a password to lock AI OS. Once a password is set, the lock screen appears every time the app starts, and the desktop stays hidden until it is unlocked.

No password set
The password is hashed with SHA-256 and stored only on this device. It is included in backups, so keep the backup file somewhere safe.

Backup

Export everything stored on this device — settings, installed apps, chat history, theme, wallpaper and app data — into one JSON file. Restoring writes those keys back; other keys are kept.

The backup contains your API key in plain text. Keep the file somewhere safe.

About

AI
AI OS
Version 1.0.1

AI OS is a desktop-style workspace that runs entirely in your browser. Describe an app in plain language and the model generates it as a draggable, resizable window; chat with AI in its own window, keep generated apps on the Start menu, and switch between dark and light themes. API keys and installed apps stay on this device.
